## Remaining Untested Scenario

**Major update that modifies entries WE translated** (e.g. SSG rewrites a quest text we have in Polish). This would overwrite our translation with new English. Our flow handles this correctly either way:
- Hash unchanged → SKIP → SSG's new English stays (correct — our translation is stale)
- Only when translators release updated polish.txt (hash changes) → RE-PATCH with version-aware translations
